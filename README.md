# TableTop Companion

Board game recommendations, reviews, videos and news for Indonesian players, in Bahasa Indonesia and English.
Recommendations use **hybrid TOPSIS** (Technique for Order of Preference by Similarity to Ideal Solution).

| Folder | What |
| --- | --- |
| [`web/`](web/) | The site: Next.js + Postgres, deploys to Vercel. **Start here.** |
| [`legacy/`](legacy/) | The original 2020 PHP/MySQL version, kept for reference only. |

See [web/README.md](web/README.md) to run, deploy, and add content.
